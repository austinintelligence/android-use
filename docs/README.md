# android-use documentation

This directory contains the deeper material behind the short root README. Choose the path that matches what you are trying to do:

## I want to use it

- [`installation.md`](installation.md) — install the skill, connect a device, add the optional helper, and verify the first session.
- [`limitations.md`](limitations.md) — understand what depends on Android version, OEM permissions, Chrome, or hardware.

## I want to understand it

- [`architecture.md`](architecture.md) — how the CLI, daemon, ADB transport, helper, and artifact manager fit together.
- [`benchmarks.md`](benchmarks.md) — how startup and action performance are measured.

## I want to maintain or release it

- [`release.md`](release.md) — build and release workflow.
- [`supply-chain.md`](supply-chain.md) — manifest verification, attestations, and public-tree checks.
- [`security.md`](security.md) — threat boundaries and safe reporting.

The root [`README.md`](../README.md) is the best starting point for a first-time visitor. The files here intentionally stay more precise and implementation-oriented.
