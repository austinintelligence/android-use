# Brand system

The android-use mark combines a physical device frame with a command cursor. It communicates direct device control without using an Android robot, an AI brain, neon circuitry, or a generic sparkle.

- Graphite `#171a18` is the primary ink and dark background.
- Warm paper `#f6f4ed` keeps documentation and previews calm and readable.
- Signal green `#b9f227` is reserved for active control, success, and the screen surface.
- Use `android-use` in lowercase. Use `au` only for the executable and compact technical contexts.
- Keep generous clear space around the mark. Do not add gradients, glow, fake depth, or extra AI motifs.

Repository assets:

- `assets/icon.svg` — square icon and avatar source.
- `assets/wordmark.svg` — README and documentation wordmark.
- `assets/social-preview.svg` — 1280×640 editable social-preview source.

Export social previews to PNG only at publication time so the SVG remains the editable source of truth.
