# Android Use for people

You do not need to know ADB, Rust, or Android development to use Android Use.

Start with [getting started](getting-started.md). It walks through the cable, Android prompts, setup command, and readiness check one step at a time.

Keep these nearby:

- [Setup reference](setup-reference.md) explains install locations, updates, rollback, and advanced options.
- [Known limitations](limitations.md) explains which features may vary by phone, tablet, Android version, or manufacturer.
- [Security and privacy](security.md) explains what Android Use can access and what always stays under your control.

For agent integration details, continue to [Android Use for agents](../agents/README.md).
